## Cómo usar este template

1. **Cada cliente nuevo:** copiar este archivo a `~/.hermes/clients/<slug>/meta-credentials.md`.
2. **Enviar al cliente:** junto con el link al handbook (`references/client-handbook.md`).
3. **Cliente completa y devuelve:** por email/WhatsApp (WhatsApp solo para los API keys de Composio/Postiz/Pipeboard — nunca en screenshots ni logs).
4. **Nosotros verificamos:** que cada paso esté checked antes de seguir.
5. **Almacenar una copia firmada** en el vault, con ACL al RL.

**⚠️ Importante:** este archivo NO debe commitearse a git con valores reales pegados. Usá 1Password CLI para secrets, y la plantilla con valores sensibles se almacena encriptada.
