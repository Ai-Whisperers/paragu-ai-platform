# IMAGE PROMPTS — Demo/Showcase Paraguay Business Website Template

## Concept
**"The Transformation Journey"** — Show Paraguayan businesses going from informal/no website to professional digital presence. Industry-agnostic but Paraguay-themed. Real people, real settings in Asunción.

---

## Image Palette & Style

### Color Palette
| Usage | Hex | Description |
|-------|-----|-------------|
| Primary | `#1a1a2e` | Navy authority |
| Secondary | `#e94560` | Coral warmth/CTA |
| Warning | `#f59e0b` | Urgency/"sin web" |
| Success | `#22c55e` | Transformation green |
| Paraguay Red | `#d62839` | Local identity accent |
| Paraguay Green | `#007935` | Local identity accent |
| Background | `#f8fafc` | Clean light |
| Text Dark | `#334155` | Readable |

### Photo Style
- **Real Paraguayan entrepreneurs** — Not models, not stock
- **Diverse settings** — Asunción offices, street scenes, home workspaces
- **Documentary feel** — Real moments, not posed
- **Warm but professional** — Not cold corporate, not overly casual
- **Before/after duality** — Transformation is the theme

## Technical Notes

### Aspect Ratios
- **16:9** — Hero images, wide banners, process images, Paraguay context
- **4:5** — Portrait testimonials, feature close-ups
- **1:1** — Icons, decorative elements

### Prompt Structure
Each prompt follows:
```
[SCENE] + [SUBJECT] + [ACTION/EXPRESSION] + [SETTING] + [LIGHTING] + [STYLE] + [COMPOSITION]
```

### Quality Markers
- "photorealistic 8K" — Required for AI generation
- "documentary style" — For authenticity
- "professional photography" — For polish
- "Paraguayan" + "Asunción" — Local context
- "warm" + "authentic" — Brand feeling
- Upper % negative space for text overlay — Functional
