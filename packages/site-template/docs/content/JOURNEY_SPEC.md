# Patient / customer journey specs

These are end-to-end journeys mapped to the site features.

## 1. Discovery
Entry points: home, Instagram link, Google Search.
Landing: hero → CTA → WhatsApp or booking form.

## 2. Consideration
Pages visited: services, pricing, testimonials, FAQ.
Triggers: promo banner, loyalty teaser, exit intent popup.

## 3. Booking
Form submit → WhatsApp confirmation.
Calendar availability managed by team.

## 4. Delivery
Receives service → earns loyalty points.
Team member tags visit in admin.

## 5. Loyalty loop
Points accumulate → tier upgrade → referral prompt.
Referral share → friend converts → bonus points.

## 6. Support
FAQ resolves common questions.
WhatsApp used for edge cases and rebooking.
