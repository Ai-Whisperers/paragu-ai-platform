# La Serafina Site — Technical & Content Audit

**Date:** 2026-07-12
**Auditor:** Erebus
**URL:** https://laserafina.paragu-ai.com
**Repo:** https://github.com/Ai-Whisperers/la-serafina-context

**Scope:** Next.js 16 App Router demo site at `apps/la-serafina-site/`

---

## TL;DR

**Verdict:** **B- / portfolio-quality demo, not production-ready for AIREANA.**

The site is **structurally sound**, **visually distinctive** (violet palette, Playfair Display + Inter, CSS variables for theming), **semantically rich** (proper heading hierarchy, ARIA, JSON-LD for NGO + Festival + WebSite, skip-to-content link), and **content-deep** (real data drawn from 75-doc research repo, not lorem ipsum).

But it is **architecturally thin**: **3 actual routes** (`/`, `/gn`, `/privacidad`) vs. **7 internal links** in the nav that 404, **4 internal links** in the footer that 404, and a **single-page experience** dressed up to look like an institutional site.

It works as a portfolio demo for Ivan/Kiki. It does **not** work as something to show a real client yet.

## 1. What works well

### Design system
- **Color tokens** in `content/es.json` (`theme.accent`, `accentDeep`, `warm`, `surface`, `text`, `textLight`, `textMuted`) are properly wired to CSS variables in `globals.css` (10.2 KB) and consumed consistently across Header/Footer/HomeClient.
- **Typography pairing** is on-brand: Playfair Display (display) + Inter (body). Both loaded via `next/font/google` with `display: swap` — no FOIT.
- **Visual identity** is consistent — the violet gradient strip in both header and footer creates visual continuity. Tone is right (literary, serious, not corporate).
- **No emoji, no kaomoji, no "as an AI" voice** — copy is authored, not generated by template.

### Semantics & SEO
- `<html lang="es">` set. `lang="gn"` available via `/gn` route (splash-only).
- Single H1 + 5 H2s — proper hierarchy.
- 6 JSON-LD blocks emitted (NGO, Festival, WebSite) with `@id` cross-references. This is *above* typical portfolio sites.
- Canonical, OG, Twitter Card, manifest, icon — all wired.
- `viewportFit: "cover"`, `themeColor: "#7B2CBF"` — mobile basics done.
- Skip-to-content link present (`<a href="#main">`).
- ARIA on mobile nav, on `aria-current="page"` for active nav items, on `aria-expanded` for hamburger.
- Local SEO keywords baked into `meta.keywords` (10 terms, "Eligio Ayala 907" alone is high-intent).
- `address` structured as `PostalAddress` with PY country code.

### Content depth (for a single page)
- Mission paragraphs cite **Safo de Lesbos**, **guaraní preservation**, **23 años** — these are AIREANA's *own* framing devices, lifted verbatim or near-verbatim from the source site, not generic NGO copy.
- Programs list covers **6 lines of work** (Sede, Festival, Ro'hendu, Tatucada, Aireatena, Incidencia política). Each has tagline + description + href.
- History timeline covers **6 milestones** (2003 founding, 2005 opening, 2011 French prize, 2012 Viernes, 2013 Ro'hendu, 2020 Aireatena). Could be longer — see gap analysis.
- Visit items: **Conciertos, Teatro, Poesía, Cine**. Smart: groups program types without claiming specific dates.
- Footer: address + phone + WhatsApp + email + hours + 5 coalitions + 4 donors + 7 footer links. That's a serious institutional footer.

### Privacy / OPSEC
- Footer's `note` field is explicit: **"Demo site construido sobre paragu-ai-platform. No afiliado oficialmente con AIREANA — usado para portfolio interno."**
- This is correct. The site is a portfolio demonstration, not an AIREANA endorsement, and the legal disclaimer is visible.

### Bilingual scaffolding
- `lib/content.ts` has a real `getContent(locale)` wrapper with `gn` fallback to `es`.
- `/gn` route exists (splash, points to ES).
- `Header` and `LangSwitcher` work via `localeFromPath`.
- `gn.json` is **7.6 KB** of partial translation — hero, navigation, brand. This is the same partial-bilingual pattern as `somosgay-site`.

### Content provenance
- es.json `metaDescription` and `_translator_note_es` cite specific sources: **"OPSEC", "OPSEC verdicts", "ai-whisperers", "CDE Direccionario", "19 press hits"**. The site was built from real research, not synthesized.

## 2. What does not work

### A. Nav links go to 404s (most damaging)

`navigation` in `es.json` lists **7 routes**:

| Label | Href | Live? |
|-------|------|-------|
| Inicio | `/` | ✅ 200 |
| Programación | `/agenda` | ❌ 404 |
| Espacio | `/espacio` | ❌ 404 |
| Festival de Cine | `/festival` | ❌ 404 |
| Ro'hendu | `/ro-hendu` | ❌ 404 |
| Historia | `/historia` | ❌ 404 |
| Apoyar | `/apoyar` | ❌ 404 |

Footer has the same 6 broken internal links plus `Privacidad` which exists.

This is a **portfolio killer**. If Ivan shows this to a prospect and they click "Programación" → 404. The credibility collapse is instant.

**Recommendation:** Either build the pages (high effort — see §4) or **strip the nav down to the routes that exist** for now: `Inicio`, `Privacidad`, with a "Próximamente" badge on the others.

### B. Canonical URL points to somosgay.paragu-ai.com

```html
<link rel="canonical" href="https://somosgay.paragu-ai.com" />
```

That's a **hardcoded production-blocking bug** — clearly copied from the somosgay-site template and never updated. Google will treat every page on laserafina.paragu-ai.com as a duplicate of somosgay.

**Fix:** `app/layout.tsx` line 110 — `alternates.canonical` should be `${SITE_URL}/` and `app/page.tsx` line 8 already has the right one. The issue is the layout's metadata. Need to check why both are emitted (Next.js does merge).

### C. JSON-LD has wrong Instagram handle

`layout.tsx` line 55:
```ts
"https://www.instagram.com/laserafinapy/",  // ← WRONG, has ñ
```

The verified handle from `airana.org.py` footer (cross-checked during research): **@laserapy** (without ñ). The audit doc in `la-serafina-context/METADATA-ANALYSIS.md` documents this correction.

**Fix:** Change `laserafinapy` → `laserapy` in both `layout.tsx` and Footer (if Footer references it).

### D. README is still SOMOSGAY's

`apps/la-serafina-site/README.md` is 116 lines of SOMOSGAY documentation — clinic address, Memoria 108, Donación form, DonationForm component, búsqueda index, cron jobs for somosgay probes. None of this applies to La Serafina.

**Fix:** Rewrite the README. Should be ~30 lines: stack, local dev, build, deploy, structure tree, edit-content guide, and the OPSEC note.

### E. Visit section has a glitchy character

`es.json` line 133:
```json
"detail": "Banda local, regional,偶尔 internacional"
```

That `偶尔` is Chinese for "occasionally" — leaked from a translation workflow. Should be "regional,偶尔 internacional" → "regional, ocasionalmente internacional".

### F. Single page, dressed as multi-page

The site claims 7 internal destinations. It has 3 routes. That's a **6× over-promise**.

`/gn` is a 632-byte splash pointing to ES — not a real Guaraní version.

`/privacidad` is a real page (5.6 KB) but unstyled generic boilerplate.

### G. Programmatic gaps

- **No `/api/` routes.** No contact form, no events JSON feed, no ICS calendar, no search.
- **No sitemap.xml.** `app/sitemap.ts` is missing. For a portfolio demo that's forgivable, but the repo has 135+ URLs of source material — a generated `/sitemap.xml` would be 50 lines.
- **No robots.txt** at `app/robots.ts`.
- **No JSON-LD for the Festival's individual years** (each `Festival` event should be its own `EventSeries` entry, or 21 separate `Event` entries).
- **No `BreadcrumbList` JSON-LD** even though the structure suggests breadcrumb-worthy pages.
- **No `FAQPage` JSON-LD** for the Ro'hendu page (when it exists).

### H. Visual content is zero

`public/` directory was not inspected in detail, but `app/icon.svg` and `app/opengraph-image.tsx` are present. The site has **no actual images** of the space, the team, the festival, the events. That's defensible for OPSEC reasons (real photos could identify AIREANA members) but should be **explicitly addressed** in design rationale — a "silhouette / typography-only aesthetic" choice is on-brand for a sáfico demo.

### I. WhatsApp widget placement

`components/WhatsAppFloat.tsx` (2 KB) is imported into the layout. Need to confirm it doesn't conflict with the footer CTA "Cómo apoyar". Quick visual check needed.

### J. Performance unverified

I did not run Lighthouse. For a Next.js 16 site with `next/font` and minimal JS, **expected good scores**, but not measured. The `Header` is `"use client"` — that pushes hydration to the home page. A static `Header` would be better.

## 4. Architecture assessment

### What exists

```
app/
├── layout.tsx              # Root layout (fonts, JSON-LD, Header/Footer)
├── page.tsx                # Home (ES)
├── HomeClient.tsx          # Home body (client-rendered for locale)
├── gn/page.tsx             # Splash
├── privacidad/page.tsx     # Privacy boilerplate
├── opengraph-image.tsx     # Dynamic OG image
├── icon.tsx + icon.svg     # Favicon
├── manifest.ts             # PWA manifest
├── not-found.tsx           # 404
└── globals.css             # 10 KB design tokens

components/
├── Header.tsx              # Nav + LangSwitcher
├── Footer.tsx              # Institutional footer
├── LangSwitcher.tsx        # ES/GN toggle
└── WhatsAppFloat.tsx       # Floating WhatsApp

content/
├── es.json                 # 9.6 KB — all copy lives here
└── gn.json                 # 7.6 KB — partial GN

lib/
└── content.ts              # Multi-locale wrapper
```

**Total TS/TSX:** ~1,500 LOC. **Total JSON content:** ~17 KB. **Total CSS:** 10 KB.

### What's missing (to match the demo's own nav promise)

| Page | Effort | Impact |
|------|--------|--------|
| `/agenda` (events list) | Medium — needs data structure for recurring "Viernes Culturales" + Festival dates | High — first thing prospects check |
| `/espacio` (venue hire) | Low — 1 page with rates, capacity, photos, contact form | High — revenue-relevant |
| `/festival` (festival hub) | Medium — needs 21 edition cards, jury, films | Highest — flagship program |
| `/festival/[year]` | High — 21 dynamic pages | Medium — depth |
| `/ro-hendu` | Low — helpline details, hours, what to expect | High — service line |
| `/historia` | Medium — full timeline (research has 100+ events) | Medium — credibility |
| `/apoyar` | Medium — donation methods, donors, transparency | High — fundraising |

If we build all of these, the demo becomes a **legitimate multi-page experience** that could be shown to AIREANA directly (with their permission).

### What the existing pattern (somosgay-site) has that la-serafina-site lacks

The somosgay-site has **45+ routes** including `/clinica-kunuu`, `/memoria-108`, `/donar`, `/transferencia`, search index, RSS feed, eventos ICS feed. The La Serafina site is **somosgay-site v0.1** — the minimal scaffold.

This is fine for a first iteration but the gap is the entire work plan for v1.

- **Result:** Production-grade portfolio piece that AIREANA could adopt.

## 7. What this site IS, accurately

- A **portfolio demonstration** of Ai-Whisperers' ability to build a serious institutional site from public-domain research
- A **proof of concept** for the `paragu-ai-platform` template pattern (multi-tenant, multi-locale, design tokens)
- A **research deliverable** that connects 75 docs of source material to a usable interface
- **Visually on-brand** for AIREANA without copying their actual site
- **OPSEC-safe** — no real photos of members, no private data, explicit "not affiliated" disclaimer

## 8. What this site is NOT

- A production site for AIREANA (no permission, no affiliation)
- A multi-page experience (single page with broken links)
- Bilingual (ES only, GN is a splash)
- Complete (no events, no team, no Festival detail)
- Search-optimized beyond basic JSON-LD (no sitemap, no FAQ schema)
