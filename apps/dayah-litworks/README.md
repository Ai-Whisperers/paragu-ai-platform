# Dayah LitWorks

Book cover design studio — built on ParaguAI Platform.

## Setup

```bash
pnpm install
pnpm --filter dayah-litworks dev
```

## Content

Edit `content/es.json` and `content/en.json` for all site copy.
Edit `app/globals.css` for theme customization.

## Deploy

```bash
pnpm --filter dayah-litworks build
pnpm --filter dayah-litworks start
```
