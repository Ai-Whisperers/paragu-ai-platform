# INDUSTRY FEATURE MAP
## Which Features to Recommend for Each Business Type

**Purpose:** Help clients understand which features are most valuable for their specific industry. Use this when recommending features to new clients.

---

## HOW TO USE THIS MAP

Each industry section includes:
- **Recommended tier** (Basic/Pro/Premium)
- **Must-have features** (non-negotiable)
- **Strongly recommended** (high impact)
- **Nice to have** (adds value but not critical)
- **Content tips** (what images/text to emphasize)

---

## 1. PELUQUERÍA / SALÓN DE BELLEZA

**Recommended Tier:** Pro (G. 250k/mes)

### Must-Have Features

| Feature | Why | Content Needed |
|---------|-----|---------------|
| Reservas online | Clientas reservan 24/7 sin WhatsApp | Service list with durations |
| Programa de lealtad | Clientas vuelven para acumular puntos | Point values per service |
| Gift cards | Regalo perfecto para ocasiones especiales | 3 card tiers (100k/250k/500k) |
| WhatsApp integrado | Canal principal de comunicación | Business WhatsApp number |

### Strongly Recommended

| Feature | Why | Content Needed |
|---------|-----|---------------|
| Catálogo de servicios | Mostrar todos los servicios con precios | Full service menu |
| Galería (antes/después) | Transformation visual es clave | 5-10 antes/después fotos |
| Pagos digitales | Clientas prefieren no usar cash | Mercado Pago / Tigo Money |

### Nice to Have

| Feature | Why |
|---------|-----|
| Blog | Tips de cuidado del cabello, tendencias |
| Instagram feed | Show off your work |
| E-commerce | Vender productos capilares |

### Content Priorities

1. **Hero image:** Salon interior, transformation shot
2. **Gallery:** Before/after is the hero content
3. **Services:** Categorized by treatment type (color, corte, tratamientos)
4. **Testimonials:** Focus on new client discovery via Google

### Sample USP for Peluquerías

> "Clientas nuevas nos encuentran en Google. Nuestras clientas fidèle vuelven por puntos."
