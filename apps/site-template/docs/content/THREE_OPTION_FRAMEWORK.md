# 3-option reconciliation

Apply to proposals when client hesitates.

## Option A — “Safe”
Same scope, split payments / calendar.
Goal: remove budget objection while preserving value.

## Option B — “Focused”
Lower scope, same budget, faster launch.
Goal: reduce risk and shorten sales cycle.

## Option C — “Growth”
Same scope plus added feature or add-on.
Goal: increase deal value and prove ROI path.

## Rule
Never present fewer than 3 options.
Never lead with price discount.
