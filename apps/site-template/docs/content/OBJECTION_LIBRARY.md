# Objection library

Objections grouped by type. Answer each with position + proof.

## Pricing
- "Es caro."
  - Position: durable result, insured materials, included care.
  - Proof: before/after gallery + cost-per-visit math.

- "Tengo presupuesto ajustado."
  - Position: payment plans and packages.
  - Proof: membership discount and 3-month option.

## Timing
- "Ahora no puedo."
  - Position: 48-hour booking window.
  - Proof: limited slots + WhatsApp hold.

## Trust
- "Nunca fui, ¿son buenos?"
  - Position: certified team + public reviews.
  - Proof: testimonials + first-visit guarantee.

## Comparison
- "Otro lugar es más barato."
  - Position: total cost includes care and outcomes.
  - Proof: warranty and product inclusions.
