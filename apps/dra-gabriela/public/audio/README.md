# Voice Intro Audio Files

Place Dr. Gabriella's recorded audio introductions here:

- `dra-gp-intro-en.mp3` — 60-90s English intro ("Hi. I'm Dr. Gabriella...")
- `dra-gp-intro-es.mp3` — 60-90s Spanish intro ("Hola. Soy la Dra. Gabriella...")

Until these files are uploaded, the `<VoiceDoctor />` component gracefully falls
back to the text transcript — which is the same content, just rendered as text.

Recording tips:
- Quiet room, lapel mic or phone headset
- Conversational tone (not "announcer")
- 60-90s = ~10-12 sentences
- 96 kbps MP3 mono is plenty for voice
- File size will be ~1-1.5 MB per file
